
  # Blogger Site Setup

  Place the logo image you attached as `public/logo.png` (Vite serves files from `public/` at the site root). If you name it differently, update the `src` in `src/components/Header.tsx` or use the `Logo` component.

  This is a code bundle for Blogger Site Setup. The original project is available at https://www.figma.com/design/BpiR1CvQ8LmRLwmjZisN3U/Blogger-Site-Setup.

  ## Running the code

  Run `npm i` to install the dependencies.

  Run `npm run dev` to start the development server.
